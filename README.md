# Smart Object Detection System using YOLO

## Project Overview
This project implements an object detection system using YOLOv8.  
It detects and counts objects in both images and videos using a pre-trained model.

The system demonstrates a complete computer vision pipeline, including inference, visualization, and basic analytics.

---

## Features
- Object detection on images  
- Object detection on videos  
- Bounding box visualization with class labels and confidence scores  
- Object counting (total objects and per class)  

---

## Technologies Used
- Python  
- OpenCV  
- Ultralytics YOLOv8  
- Google Colab
